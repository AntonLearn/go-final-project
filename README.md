# 📅 Todo Scheduler

**Веб-сервер планировщика задач** с поддержкой повторяющихся задач и удобным веб-интерфейсом.

---

## ✨ Описание проекта

Проект представляет собой полноценный планировщик задач, реализованный в виде веб-сервера на Go. 

Каждая задача содержит **заголовок**, **комментарий** и **дедлайн**. Поддерживается **гибкая система повторения** задач (ежегодно, каждые N дней, в определённые дни недели/месяца и др.). При выполнении повторяющейся задачи она автоматически переносится на следующую дату согласно правилу. Обычные задачи после выполнения удаляются.

Используется база данных **SQLite** (`scheduler.db`).

### Основной функционал

- Добавление новой задачи
- Получение списка задач
- Удаление задачи
- Получение и изменение параметров задачи
- Отметка задачи как выполненной

---

## 🚀 Дополнительные возможности

Реализованы **все** дополнительные требования:

- Возможность указать порт при запуске
- Полная поддержка всех видов правил повторения задач
- Настройка пути к файлу базы данных через переменную окружения
- Поиск задач по дате или подстроке
- Механизм JWT-аутентификации
- Запуск приложения в **Docker** контейнере

**Дополнительно реализовано:**
- Подробное логирование в файл `app_YYYY-MM-DD_hh-mm-ss.log`
- Сброс логина (маршрут `/api/signout`)
- Плавное завершение работы приложения (graceful shutdown)

---

## ⚙️ Переменные окружения

При запуске приложение считывает следующие переменные:

| Переменная         | Описание                        | Значение по умолчанию          |
|--------------------|---------------------------------|--------------------------------|
| `TODO_WEB_DIR`     | Путь к папке с веб-файлами      | `web`                          |
| `TODO_PORT`        | Порт сервера                    | `7540`                         |
| `TODO_DBFILE`      | Путь к файлу базы данных        | `scheduler.db`                 |
| `TODO_PASSWORD`    | Пароль для входа                | `password`                     |
| `TODO_SECRET`      | Секретный ключ для JWT          | `your-secret-key-here`         |

## 🐳 Docker

### Сборка образа

```bash
docker build --no-cache -t todo-app:latest .
```

### Запуск контейнера

**Без переменных окружения:**

```bash
docker run -d --name todo-scheduler -p 7540:7540 todo-app:latest
```

**С переменными окружения:**

```bash
docker run -d --name todo-scheduler \
  -p 7540:7540 \
  -e TODO_PORT=7540 \
  -e TODO_DBFILE=scheduler.db \
  -e TODO_PASSWORD=password \
  -e TODO_SECRET=your-secret-key-here \
  -e TODO_WEB_DIR=web \
  todo-app:latest
```
